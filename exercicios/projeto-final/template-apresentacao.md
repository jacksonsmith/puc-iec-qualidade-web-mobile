# Modelo de apresentação — Seminário Técnico (~20 min)

> Sugestão de roteiro de slides. Use como guia, não como obrigação. **O grupo decide quem fala.**

| # | Slide | Conteúdo | Tempo |
|---|---|---|---|
| 1 | Capa | tema em uma frase, nomes do grupo | — |
| 2 | O problema | que dor ou risco de qualidade o tema ataca; um exemplo real | 3 min |
| 3 | Por que importa | custo de ignorar; quem é afetado | |
| 4 | O que dizem as fontes | 2 ou 3 fontes fortes (blog de engenharia, autor de referência, paper, doc oficial) | 6 min |
| 5 | Abordagens e trade-offs | comparação: o que cada uma resolve e o que custa | |
| 6 | Achados | o que o grupo concluiu; número, print ou comparação | 6 min |
| 7 | Demo (opcional) | só se couber; tenha print ou gravação como plano B | |
| 8 | Limites | o que não funcionou ou não cobre | 2 min |
| 9 | Referências | autor, título, link, data de acesso | |
| 10 | Perguntas | | 3 min |

**Dicas**

- Poucas palavras por slide; a explicação é falada.
- Mostre de onde veio cada afirmação importante (fonte).
- Escopo pequeno: é melhor aprofundar um recorte do que passar por cima de um tema inteiro.
- Ensaie o tempo: 20 minutos passam rápido.
